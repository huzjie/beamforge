# 可复用模式

1. **稀疏即一等公民**：所有成本（通信/FLOPs/内存）都按活跃参数算，用 `SparseAccountant` 显式记账。
2. **自愈 = 便宜恢复**：先分类故障，再选最便宜的恢复动作，用中位数做 SLO。
3. **沙箱池化**：海量环境靠池化复用 + 弹性伸缩，不靠同时常驻。
4. **可训练 mock 后端**：skill 参与打分 + 恒正 delta，训练信号单调，基准可复现。
5. **零依赖 YAML**：`utils/yamlish.py` 兜底，裸 Python 也能读配置。
6. **确定性随机**：`md5(key)` 前 8 字节做种子，训练与基准跨 run 稳定。
